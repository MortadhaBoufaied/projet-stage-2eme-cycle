# Setup

1. Keep `.env` beside the `src` directory.
2. Change `ADMIN_USERNAME` and `ADMIN_PASSWORD` before deployment.
3. Start the app from the project root:

```bash
streamlit run src/ui/app.py
```

Default development account included in `.env`:

- Username: `admin@finance.local`
- Password: `ChangeMeNow!2026`

Change this password immediately. Do not commit `.env` to source control.
